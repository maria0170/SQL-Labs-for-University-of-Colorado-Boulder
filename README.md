# SQL-Labs-for-University-of-Colorado-Boulder
The University of Colorado Boulder offers hands-on SQL labs  where lectures are paired with practical lab assignments and exercises focused on ANSI standard SQL commands and syntax.

This repository contains my completed SQL lab assignments from the University of Colorado Boulder, where I developed practical skills in writing and analyzing queries using ANSI-standard SQL. The labs combine lecture concepts with hands-on exercises to build a strong foundation in relational database management.

What I learned

Throughout these labs, I practiced:

Writing SQL queries to retrieve, filter, sort, and analyze data
Using aggregate functions, GROUP BY, and HAVING to summarize datasets
Combining multiple tables with INNER and LEFT JOIN operations
Creating and modifying database tables using DDL commands (CREATE, ALTER, DROP)
Managing data with DML statements (INSERT, UPDATE, DELETE)
Applying subqueries and relational database principles to solve real-world data problems
These exercises strengthened my understanding of database design, data manipulation, and efficient querying for structured datasets.
